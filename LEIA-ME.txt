PROJETO: SISTEMA DE ACHADOS E PERDIDOS DA ESCOLA

Aluno/Grupo: ______________________________
Turma: ____________________________________

OBJETIVO: Registrar objetos encontrados na escola.
LINGUAGEM: Python 3

FUNCIONALIDADES:
1 - Cadastrar objetos
2 - Listar objetos
3 - Excluir objetos (com motivo e confirmação)
4 - Sair

ARQUIVOS:
achados_perdidos.py - Código principal
achados_perdidos.csv - Objetos cadastrados
objetos_excluidos.csv - Histórico das exclusões
LEIA-ME.txt - Instruções

COMO EXECUTAR:
1. Extraia o arquivo ZIP no computador.
2. Abra a pasta achados_e_perdidos no Visual Studio Code.
3. Verifique se o Python 3 está instalado.
4. Abra o terminal na pasta do projeto.
5. Execute: python achados_perdidos.py
   No Windows, se necessário, use: py achados_perdidos.py
6. Digite as opções de 1 a 4 no terminal.

COMO CONFERIR SEU PROJETO:
- Opção 1: cadastre um objeto com nome, descrição, local e data.
- Opção 2: confira se o objeto aparece na listagem.
- Encerre e abra o programa: o objeto deve continuar cadastrado.
- Opção 3: informe o número, motivo e confirme com S.
- Confira se o objeto saiu de achados_perdidos.csv e entrou em objetos_excluidos.csv.
- Teste uma opção inválida e a opção 4 para sair.

OBSERVAÇÕES:
- O projeto utiliza apenas bibliotecas padrão do Python, sem instalações extras.
- Os CSVs começam apenas com o cabeçalho, sem dados fictícios.
- Os arquivos CSV ficam na pasta do projeto.
- A data é recebida como texto no formato indicado na aula (dd/mm/aaaa).
- A entrega original das aulas pede atualização do GitHub e print no Classroom.
